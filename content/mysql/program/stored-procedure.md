## 问题

MySQL 存储过程是什么？它有哪些优缺点？

## 答案

存储过程是保存在数据库中的一组可参数化 SQL 和控制流程，通过 `CALL` 执行。它适合靠近数据的批处理、运维任务或需要减少多次网络往返的固定流程。

优点是可复用、在数据库侧执行并能集中授权；缺点是业务逻辑容易分散到应用与数据库两处，版本管理、调试、单元测试、可观测性和跨数据库迁移都更困难，还可能把大量计算压力集中到数据库。

在常见 Spring 服务中，核心支付状态机通常放在应用 Service/Domain 层，数据库负责约束和原子读写。确实使用存储过程时，应像代码一样纳入 Flyway、评审、权限控制、超时和回滚测试，而不是直接在线上手改。
