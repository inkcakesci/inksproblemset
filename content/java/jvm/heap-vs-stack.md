## 问题

JVM 堆和 Java 虚拟机栈有什么区别？对象和引用分别存在哪里？

## 答案

堆主要保存对象实例和数组，由所有线程共享并由垃圾收集器管理；Java 虚拟机栈是线程私有的，主要保存每次 Java 方法调用对应的栈帧。

栈帧包含局部变量表、操作数栈、动态链接和方法返回信息等。局部变量表可以保存基本类型值和对象引用，但引用指向的对象通常位于堆中：

```java
User user = new User();
```

局部变量 `user` 的引用位于当前方法栈帧中，`User` 对象通常位于堆中。

方法返回后，对应栈帧出栈；堆对象在不再可达后，才可能被 GC 回收。不能简单认为“栈一定快、堆一定慢”，实际性能还受到 JIT 优化、逃逸分析、缓存和对象布局等因素影响。
