## 问题

Java 接口和抽象类有什么区别？应该如何选择？

## 答案

抽象类适合表达一组对象的共同身份、状态和复用实现；接口适合定义可跨不同继承体系组合的能力或契约。

抽象类可以有实例字段、构造器、普通方法和抽象方法，一个类只能直接继承一个父类。接口不能保存每个实现对象的实例状态，字段隐式为 `public static final`；它可以声明抽象方法，并支持 `default`、`static` 和私有辅助方法。一个类可以实现多个接口。

选择时可以考虑：

- 多个类存在稳定的“is-a”关系，并需要共享状态或基础实现：使用抽象类。
- 只需要规定“能做什么”，希望不同类型都能获得该能力：使用接口。
- 两者可以组合：抽象类复用公共实现，同时实现若干接口对外表达能力。

“抽象类描述是什么，接口描述能做什么”是便于记忆的概括，但不是语言层面的硬性限制。
