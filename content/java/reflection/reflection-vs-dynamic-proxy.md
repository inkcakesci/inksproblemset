## 问题

Java 反射和动态代理分别解决什么问题？Spring AOP 如何同时用到它们？

## 答案

反射主要解决“如何在运行时发现类型结构并动态调用”；动态代理主要解决“如何让调用先经过代理对象，在目标方法前后插入统一逻辑”。

以 Spring 声明式事务为例：

1. Spring 读取类和方法上的事务元数据。
2. 为符合条件的 Bean 创建代理对象。
3. 外部调用先进入代理和事务拦截器。
4. 拦截器开启事务、调用目标方法，再提交或回滚。

JDK 动态代理面向接口生成代理，调用处理器中常通过反射调用目标方法；Spring 也可以使用基于子类生成的代理。反射和代理有关联，但不是同一个概念：反射不一定创建代理，动态代理的底层实现也不一定只依赖传统反射调用。
