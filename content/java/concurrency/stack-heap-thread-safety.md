## 问题

为什么常说栈天然线程安全，而堆中的对象可能线程不安全？这个说法有什么限制？

## 答案

每个线程拥有独立的 Java 虚拟机栈，因此一个方法调用的栈帧和局部变量本身通常不会被其他线程直接访问，这提供了线程隔离。

但局部变量如果保存对象引用，引用指向的堆对象仍可能被多个线程共享。因此“局部引用在栈上”不代表它指向的对象自动线程安全。

堆由线程共享，但“位于堆中”也不等于一定不安全：不可变对象、只读对象、线程封闭对象，或者受到正确同步保护的可变对象都可以安全使用。真正的问题是多个线程在缺少同步的情况下并发读写共享可变状态。

判断口诀：关注对象是否“共享且可变”，而不是只看它分配在堆还是栈。
