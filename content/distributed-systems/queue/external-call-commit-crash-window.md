## 问题

Worker 调用外部服务已经成功，但在保存结果或完成任务前崩溃，应该如何处理这个结果未知窗口？

## 答案

不能依赖本地事务回滚外部调用，也不能假设队列只会执行一次。应以稳定 operation ID 把外部副作用和本地结果都变成可查询、可去重的业务操作，再允许任务安全重放。

常见处理方式是：

- 外部服务支持幂等键时，每次重试复用同一个键；
- 本地结果表对 operation ID 建唯一约束或执行条件更新；
- 重试前先检查是否已有匹配的结果及结果摘要；
- 保存结果和本地 Outbox 时使用短事务；
- 最后以 Lease Token 做 CAS 完成任务。

若外部接口既没有幂等键也不能查询结果，就无法从机制上保证不重复调用，只能缩小风险、记录人工核对证据，并在业务设计中明确这种不确定性。
